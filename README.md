# Лабораторная работа: Линейные алгоритмы — Расчёт параметров полёта тела
## Автор
Карнаухов Фёдор (Вариант 3)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчёта параметров движения тела, брошенного под углом к горизонту.

## Описание
Программа запрашивает у пользователя угол броска, начальную скорость и ускорение, после чего вычисляет пять характеристик траектории: время полёта, максимальную высоту подъёма, максимальную дальность полёта и радиусы кривизны траектории в начальной точке и в вершине.

## Исходные данные
Вводятся пользователем с клавиатуры:
Угол броска alpha (в градусах)
Начальная скорость initialVelocity (м/с)
Ускорение acceleration (м/с²)

# Формулы
Время полёта: t = 2·v₀·sin(α) / a
Максимальная высота: h = v₀²·sin²(α) / (2a)
Максимальная дальность: L = v₀²·sin(2α) / a
Радиус кривизны в начале траектории: R₁ = v₀² / (a·cos(α))
Радиус кривизны в вершине траектории: R₂ = v₀²·cos²(α) / a

## Ожидаемые результаты
Программа выводит пять значений:
flight time — время полёта
maximum flight height — максимальная высота подъёма
maximum flight range — максимальная дальность полёта
radius of curvature of the start of the trajectory — радиус кривизны в начале траектории
radius of curvature of the vertex trajectories — радиус кривизны в вершине траектории
